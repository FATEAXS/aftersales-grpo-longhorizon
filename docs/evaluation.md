# 评测协议

## 四面板指标（全部确定性代码检查）

1. **终局与奖励**：严格成功率（基础分 ≥ 1.0）、平均 Reward v1、终局类型分布；
2. **合规审计**：红线违规率（风控用户退款被受理）、应拒绝任务违规办理率、
   过早升级率、政策被拒动作尝试率；
3. **沟通与澄清**：歧义任务主动澄清率、澄清后成功率、结果虚报率；
4. **效率与稳健**：平均步数、guard 拒绝、重复循环率，按难度/场景分解。

不合成单一总分；各面板独立解读。

## 盲评守卫

轨迹产物（trajectories.jsonl）经 `evaluation/artifacts.py` 扫描，TaskFacts
私有字段（期望解、可接受映射、风控标志等）一律不得出现；私有事实只在评分
阶段就地消费，聚合后以指标形式落盘。

## 报告

`evaluate.sh <name>` 自动产出 `summary.json` + `report.html`（单文件、零外部
依赖）；`report_all.sh` 追加跨阶段对比表（experiments/comparison.md）。
